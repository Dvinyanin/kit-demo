# MultiSelect: мультивыбор (значения строкой, список с чекбоксами)

Охват: компонент `MultiSelect` (мультивыбор): триггер со значениями через запятую и список с чекбоксами из `Dropdown [Simple]`, оба размера (Default и Micro). `Select` только для одиночного выбора. Остальное поведение триггера (состояния, иконки, суффикс, очистка) общее и описано в [select-default.md](select-default.md); общий попап описан в [select-dropdown-simple.md](select-dropdown-simple.md).

Статус: от 2026-10-15; вынесено из двух других спек, сверка выполнена, расхождения исправлены (§6). Micro описан как отличия от Default.

## 1. Решения

Приняты 2026-10-15:

1. Мультивыбор отображается в обычном триггере `Select [Default]`/`Select [Micro]`: выбранные значения одной строкой через запятую.
2. Вариант с тегами (`Select Multiple [Default + Micro]`, `8696:12588`) не делается: у него другой триггер (блок тегов с иконкой удаления, переменная высота). Описывается отдельно, когда понадобится.
3. Образец списка с чекбоксами: `Dropdown [Simple]` (ячейка со свойством `showCheckbox`). `Dropdown Advanced (Multi)` (поиск, блок выбранных, футер «Выбрать всё», очистка) не делается.
4. Что показывать в триггере, задаёт потребитель через `renderValue`; `Select` подписи сам не угадывает.
5. Значение всегда приходит снаружи (`value`, `onValueChange`), неуправляемого режима нет.

6. Мультивыбор вынесен в отдельный компонент `MultiSelect` (решено 2026-10-15): `Select` одиночный, без `multiple` и без чекбокс-ячейки. Оба компонента тонкие обёртки над внутренней основой `SelectField` (`src/components/Select/base/`) (триггер, иконки, очистка, попап), которая наружу не экспортируется.

## 3. API

| Что                     | Проп / компонент         | Примечание                                                                                                                                                          |
| ----------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Компонент               | `MultiSelect`            | Проп `multiple` не передаётся: задан самим компонентом. Экспортируется из `src/index.ts` вместе с типом `MultiSelectProps` (`MultiSelectBaseProps` для композиции). |
| Значение                | `value`, `onValueChange` | Значение приходит снаружи. `value={undefined}` означает «ничего не выбрано» (внутри это `[]`).                                                                      |
| Что показать в триггере | `renderValue(values)`    | Получает массив. Пример: `values.map(labelOf).join(", ")`. Без него Base UI показывает сырые значения.                                                              |
| Ячейка списка          | `MultiSelect.Base.Item`  | Чекбокс, текст, опциональная иконка слева (`iconLeft`). Subtext, суффикс и код в ней не поддержаны.                                                                 |
| Очистка                 | `clearable`              | Сбрасывает в `[]` через `onValueChange` (общее поведение, `select-default.md` §11).                                                                                 |

## 4. Триггер

Показывает значения одной строкой в том же слоте, что и одиночное значение, с теми же токенами, геометрией и состояниями, что в [select-default.md](select-default.md) §3 и §4. Отдельных значений для мультивыбора в макете нет.

В макете (`Value 1, Value 2, Value 3`):

- Шрифт и цвет как у одиночного значения: Default 16/24, Micro 13/18 (ls 0.15), `--texticon`.
- Длинная строка обрезается многоточием (`overflow: hidden`, `text-overflow: ellipsis`, `white-space: nowrap`).
- Иконка очистки в Default-примере есть слева от шеврона (в Micro-примере нет; решено, что очистка нужна и в Micro).
- Плейсхолдер и лейбл ведут себя как у одиночного выбора: лейбл всплывает, когда есть значение.

## 5. Список с чекбоксами

Ячейка общая с одиночным списком (`select-dropdown-simple.md` §4: padding, gap, шрифты, фон при наведении `--bg-surface-level2-hover`, высота 40 и 26), но вместо иконки `icon-check` справа слева стоит чекбокс. Иконка выбранного справа вместе с чекбоксом не используется.

| Параметр                 | Default                                  | Micro       |
| ------------------------ | ---------------------------------------- | ----------- |
| Размер чекбокса          | 18×18                                    | **16×16**   |
| Радиус                   | 4                                        | как Default |
| Не выбран: фон, рамка    | `--bg-surface`, 1px `--border-silver`    | как Default |
| Выбран: заливка, галочка | `--bg-accent` (`#97BA1E`), белая галочка | не снято ¹  |
| Размер галочки           | 14×14 внутри бокса 18 (занимает x 4–14)  | 12×12       |
| Gap чекбокс и текст      | 12                                       | **8**       |
| Положение                | слева от текста, по центру высоты ячейки | как Default |

¹ Выбранный Micro-чекбокс в макете не снимал; в коде тот же `--bg-accent`, галочка уменьшена пропорционально.

Список остаётся открытым после выбора элемента (поведение Base UI при `multiple`).

## 7. Вопросы и недоделки

- **Micro:** выбранный чекбокс не снят в макете, мультивыбор со значением в Storybook для Micro не измерялся.
- **`MultiSelect.Base.Item`:** subtext, суффикс и код не поддерживаются; в макете для ячейки с чекбоксом они не проверялись.
- **Теги** (`Select Multiple`) и **`Dropdown Advanced (Multi)`** не делаются; когда понадобятся, описываются отдельными спеками.
- **Группы и вложенность** в мультивыборе (`NestedGroup`, `Dropdown [Nested]`) не сверялись.
