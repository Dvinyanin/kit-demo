# Select: попап Dropdown Simple (Default + Micro)

Охват: выпадающий список для выбора одного значения (`Dropdown [Simple]` и `Dropdown Micro [Simple]`) и его ячейки: Value, Value + Subtext, Value + Suffix, Code + Value, Icon + Value, No Items. Статус-ячейки, группы, вложенность, поиск и ComboBox описываются отдельными спеками. Мультивыбор (ячейка с чекбоксом) описан в [select-multiple.md](select-multiple.md).

В коде это `SelectPopup` и `Item` в `src/components/Select/base/SelectShared.tsx` (общие для Select, MultiSelect и SelectCompact). Micro-часть описана как отличия от Default.

Статус: от 2026-10-15; сверка выполнена, расхождения исправлены (§8). Нерешённое (наведение, скролл, пустой список, высота списка) в §7.

| Тень контейнера                  | `--shadow-popover-500`        |
| Значение                         | `--texticon`                  |
| Subtext, суффикс, код            | `--texticon-secondary`        |

| Полоса прокрутки (thumb)         | `--texticon-quaternary`       |
| Фон ячейки при наведении         | `--bg-surface-level2-hover` ² |

| Пустой список, Micro             | `--texticon-disabled` ¹       |

Иконка выбранного: `#505F79`, непрозрачная, в обоих размерах = `--neutral-300` = `--texticon-medium`.

¹ Default и Micro используют разные токены для текста «Не найдено». Пустой список пока не делаем, вопрос к дизайнеру откроется вместе с ним.

² Не из `Dropdown [Simple]`: там ячейки в состоянии наведения нет. Токен взят из Showcase `Dropdown [Nested]` (`893:224827`) по решению пользователя.

В тёмной теме `--bg-surface-level2` отличается от `--bg-surface` (`--dark-neutral-800` против `--dark-neutral-900`), поэтому подмена токена не безразлична.

## 5. Поведение

- Выбранное значение отмечено иконкой `icon-check` справа. Фона у выбранной ячейки нет.
- Наведение: «при открытии меню ховер на выбранном значении (по возможности); при наведении на другие значения ховер больше не фиксируется на выбранном». Фон ячейки при наведении `--bg-surface-level2-hover` (`#F6F8FC`), взят из Showcase `Dropdown [Nested]` (`893:224827`): в `Dropdown [Simple]` ячейки в состоянии наведения нет.
- Зазор между полем и меню 4px.
- Анимация появления меню (150 ms `cubic-bezier(0.7, 0, 0.84, 0)`) в макете задана, в код не переносится.

## 6. Размещение в вёрстке (для сверки)

Ожидаемые значения при размере Default (в скобках Micro), измеряются в Storybook на открытом попапе:

- Высота ячейки с одной строкой: 40 (26).
- Высота ячейки с subtext: 10 + 20 + 2 + 16 + 10 = 58 (5 + 16 + 2 + 14 + 5 = 42).
- Левый край текста от левого края попапа: 6 + 10 = 16 (6 + 6 = 12).
- Размер иконки выбранного: 20 (16); цвет `rgb(80, 95, 121)`.
- Иконка выбранного по центру ячейки по вертикали, в том числе в ячейке с subtext.

## 7. Ошибки макета и вопросы к дизайнеру

Решено (2026-10-15):

1. **Наведение на ячейку.** Токен взят из примера, который дал пользователь: `--bg-surface-level2-hover` (Showcase `Dropdown [Nested]`, `893:224827`). В `Dropdown [Simple]` такой ячейки нет, поэтому источник не из Simple-спецификации.
2. **Прокрутка.** Простой скролл, без стрелок. Полоса из макета: 6px, радиус 3, `--texticon-quaternary`.
3. **Высота списка.** Пока не ограничиваем: список тянется до края окна (`max-height: var(--available-height)`). В макете максимум 252 (Micro 220).
4. **Пустой список «Не найдено».** Пока не делаем.
5. **Status-ячейка.** `Item` принимает любое содержимое в `children`, StatusTag в него вставляется как есть. Отступы ячейки меняются через `--select-cell-padding` (`style` или `className`): в макете у ячейки со статусом `8px 10px` (Default). Сам компонент StatusTag не входит в эту спеку.

Для дизайнера (исправить в Figma):

6. **Icon + Value:** цвета иконок в макете заданы самими SVG (приоритеты), для произвольных иконок цвет не определён. В коде `--texticon-secondary`.
7. **Имена типов:** `Value+Suffix` в Showcase и `Value+Txt` в библиотеке; `Code+Value` и `00000+Value` в Micro.
8. **У Micro `Content` контейнера** `max-h 300`, а у списка 208: фактический максимум 220, поле 300 недостижимо.
