# Checkbox

Охват: компонент `Checkbox` (чекбокс с тремя состояниями: выключен, включен, включен частично) в размерах Medium и Small, с лейблом справа, слева или без него.

Статус: от 2026-10-15; собрано автономно по макету; сверка по скриншотам матрицы историй (§8). Решения «на моё усмотрение» помечены в §7.

## 2. API

| Свойство в Figma                               | Проп в коде                                    | Примечание                                                                                            |
| ---------------------------------------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `Size=Medium` / `Small`                        | `size="medium"` / `"small"`                    | По умолчанию `medium`                                                                                 |
| `Checked=Off` / `On`                           | `checked={false}` / `{true}`                   | Только управляемый режим: `checked` и `onCheckedChange(checked)`; `defaultChecked` нет (как у Select) |
| `Checked=Indeterminate`                        | `indeterminate`                                | Перекрывает `value` внешним видом; `aria-checked="mixed"`                                             |
| `Disabled=True`                                | `disabled`                                     |                                                                                                       |
| `Error=True`                                   | `invalid`                                      | Имя как у `Select`; в макете «Error»                                                                  |
| `State=Hover` / `Active`                       | CSS `:hover`, `:active`                        | Состояния от мыши, пропсов нет. Hover реагирует и на лейбл (курсор в макете стоит на лейбле)          |
| Label, `Label Position` (Right, Left, Without) | `children`, `labelPosition="right"` / `"left"` | Без `children` лейбла нет (Without), нужен `aria-label`. Right по умолчанию                           |
| —                                              | `readOnly`, `required`, `name`, `value`, `id`  | Из Base UI, в макете нет                                                                              |

## 3. Токены (состояние × элемент)

Не выбран (`Checked=Off`): рамка 1px.

| Элемент | Default           | Hover             | Active                   | Disabled                   |
| ------- | ----------------- | ----------------- | ------------------------ | -------------------------- |
| Фон     | `--bg-surface`    | `--bg-surface`    | `--bg-accent-muted`      | `--bg-surface-disabled`    |
| Рамка   | `--border-silver` | `--border-accent` | `--border-accent-active` | `--border-silver-disabled` |
| Лейбл   | `--texticon`      | `--texticon`      | `--texticon`             | `--texticon-disabled`      |

Не выбран + Error:

| Элемент | Default           | Hover                    | Active                   |
| ------- | ----------------- | ------------------------ | ------------------------ |
| Фон     | `--bg-surface`    | `--bg-surface`           | `--bg-danger-muted`      |
| Рамка   | `--border-danger` | `--border-danger-active` | `--border-danger-active` |

Выбран (`On`) и частично (`Indeterminate`): заливка без рамки, метка (галочка или чёрточка).

| Элемент | Default            | Hover               | Active               | Disabled              | Error              | Error Hover         | Error Active         |
| ------- | ------------------ | ------------------- | -------------------- | --------------------- | ------------------ | ------------------- | -------------------- |
| Заливка | `--bg-accent`      | `--bg-accent-hover` | `--bg-accent-active` | `--bg-semisilver`     | `--bg-danger`      | `--bg-danger-hover` | `--bg-danger-active` |
| Метка   | `--texticon-white` | `--texticon-white`  | `--texticon-white`   | `--texticon-disabled` | `--texticon-white` | `--texticon-white`  | `--texticon-white`   |
| Лейбл   | `--texticon`       | `--texticon`        | `--texticon`         | `--texticon-disabled` | `--texticon`       | `--texticon`        | `--texticon`         |

Как получены токены выбранного состояния (цвет в SVG, не переменной): заливка `#97BA1E` = `--bg-accent`, `#81A11A` = `--bg-accent-hover`, `#547012` = `--bg-accent-active`; `#F14D56` = `--bg-danger`, `#C13E45` = `--bg-danger-hover`, `#912E34` = `--bg-danger-active`; Disabled `#455893` при `fill-opacity 0.1` = `--bg-semisilver` (`--neutral-40-adapt`), метка `#95A0B3` = `--texticon-disabled`; метка `white` = `--texticon-white`. Состояния Indeterminate совпали с On по заливке (проверены Default и Disabled), в остальных предполагается то же. Disabled + Error и Read Only в макете нет.

## 4. Геометрия

| Параметр                    | Medium                            | Small                             |
| --------------------------- | --------------------------------- | --------------------------------- |
| Коробка                     | 18×18, радиус 4, рамка 1          | 16×16, радиус 4, рамка 1          |
| Вертикальный отступ коробки | `(1lh − 18) / 2`: 2 при строке 22 | `(1lh − 16) / 2`: 0 при строке 16 |
| Gap коробка и лейбл         | 12 (`$space-300`)                 | 8 (`$space-200`)                  |
| Лейбл                       | 16/22, ls 0 (`body-large`)        | 12/16, ls 0.2 (`body-small`)      |
| Галочка (внутри коробки)    | x 4–14, y 5.3–13                  | x 3.5–12.5, y 4.5–11.5            |
| Чёрточка                    | x 4–14, y 8–10, скругление 1      | x 3.5–12.5, y 7–9, скругление 1   |

Геометрия метки взята из путей SVG макета и рисуется встроенным SVG (иконка `check` из набора отличается формой). Без лейбла высота чекбокса равна строке окружающего текста (`1lh`): корень не задаёт свою типографику и наследует окружение, поэтому чекбокс встаёт в строку, а отступ коробки считается от `1lh`. С лейблом корень получает типографику размера (`font` и `letter-spacing`). Лейбл слева: порядок «лейбл, коробка», те же gap и выравнивание. Многострочный лейбл переносится по словам, коробка выровнена по первой строке (Grouped).

## 5. Поведение

- Клик по коробке или по лейблу переключает значение.
- Hover и Active относятся ко всему контролу, подсвечивается коробка.
- Disabled: не реагирует на мышь и клавиатуру, `cursor: not-allowed`, цвета Disabled.
- Анимации в макете нет.
- Фокус с клавиатуры: кольцо `--effects-focus-ring` вокруг коробки (в макете состояния нет, решение «как у кнопок»).
- Read Only: не переключается, без Hover и Active (в макете нет).

## 6. Размещение в вёрстке (для сверки)

Рекомендованные интервалы внутри группы (Showcase, `Grouped`): вертикально 12, горизонтально 16. Это рекомендация для страниц, не стиль компонента; в историях `Grouped` показаны оба.

## 7. Решения и вопросы к дизайнеру

Решено автономно (2026-10-15):

1. Без `defaultChecked`: только управляемый режим, имена `value` и `onChange` (как у `Select`).
2. Ошибка называется `invalid` (как у `Select`), а не `error`.
3. Фокус с клавиатуры, Read Only и Disabled + Error в макете не заданы: сделаны по аналогии (§5).
4. Тёмная тема: берутся те же семантические токены; тёмные ячейки Showcase не сверялись по значениям.

Для дизайнера: в состояниях Off + Disabled в макете нет Error + Disabled; уточнить, нужен ли.
